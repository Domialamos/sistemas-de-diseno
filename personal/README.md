# Personal

Subsistema para todo lo que no es trabajo: proyectos propios, un temporizador Pomodoro, invitaciones y regalos. Toma como referencia a serious.business.

**Estado:** hay que reconstruirlo. Por ahora existe solo esta descripción.

## Esencia

Rosa a página completa, tipografías mezcladas dentro de la misma frase y formas redondeadas. Es el único subsistema que admite esquinas curvas.

## Tokens

| Rol | Color |
|---|---|
| Fondo | `#FBC1D4` (rosa chicle) |
| Tinta | `#1E1E1E` |
| Acento | `#FF7EC4` (rosa fuerte) |
| Acento | `#C3ABFF` (lila) |
| Acento | `#FED35B` (amarillo) |

## Tipografía

Avenir Next y Georgia, mezcladas en la misma frase.

## Formas

- Píldoras de 999 px y radios de 12 px.
- Sin sombras.

## Prohibiciones

- No se usa en piezas de trabajo.
